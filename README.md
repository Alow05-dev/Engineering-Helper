# Engineering Copilot Ultimate

GitHub Pages-ready standalone engineering study application.

## Deploy
1. Create a GitHub repository.
2. Upload `index.html`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save.

## Included
- Responsive premium UI
- Engineering discipline selector
- Homework workspace
- Step-by-step / hint / teaching / practice modes
- Local Electrical AC power and Ohm's Law recognition
- Ohm's Law calculator
- Single-phase AC power calculator
- Unit converter
- Quadratic solver
- Complex number calculator
- Percent error calculator
- Local browser session history
- Homework image/document upload UI
- Mobile-friendly layout

## AI/OCR
This build intentionally runs without API keys or a backend. The UI is structured so an AI API and OCR service can be connected later for true image-to-solution and natural-language engineering solving.
