# Engineering Copilot

A polished, standalone engineering homework assistant UI designed for GitHub Pages.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`.
3. Open **Settings → Pages**.
4. Set deployment to **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

The current version is frontend-only. AI solving, OCR/image analysis, cloud saving, and advanced engineering calculation engines can be connected to a backend/API in the next version.
